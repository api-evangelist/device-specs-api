# Device Specs API

A read-only REST API delivering clean, normalized JSON specifications for mobile devices — phone specs, chipsets/SoCs, display metrics, battery, CPU, memory, camera, and physical dimensions. Covers 12,000+ devices, distributed via the RapidAPI gateway with an official C# NuGet SDK.
