# Device Specs API

A normalized mobile-device specifications REST API covering 12,000+ smartphones, delivering cleaned/structured JSON for chipsets, display metrics, CPU/RAM/storage, battery & charging, cameras, physical dimensions, connectivity, benchmarks, and EU energy-label data. Distributed and sold via RapidAPI.

## APIs

- **Device Specs API** — REST API for normalized mobile-device specifications, fronted by the RapidAPI gateway. Provides device specs by manufacturer/model, devices by brand, devices by chipset, and a query-param filter engine. Auth via RapidAPI key headers (x-rapidapi-key, x-rapidapi-host). (`https://gsmarenaparser.p.rapidapi.com`)

> Conventional REST API distributed via RapidAPI with a public OpenAPI 3.0.3 contract (https://ds.gtgroup.dev/openapi.json). A free BASIC tier makes it publicly consumable (RapidAPI key required). APIs.json at https://ds.gtgroup.dev/apis.json, a Spectral governance ruleset at https://ds.gtgroup.dev/spectral.yaml, and an API-onboarding manifest at https://ds.gtgroup.dev/.well-known/api-onboarding are also public. An official C#/.NET NuGet SDK 'DeviceSpecs' exists (https://www.nuget.org/packages/DeviceSpecs). No agent-native surface: no hosted MCP server, no llms.txt, no agent skills. The apis.json 'AgentPrompt' merely links to the human docs page and does not constitute an agent-native interface despite marketing claims of being 'AI-agent friendly'.
